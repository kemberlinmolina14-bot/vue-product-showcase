# 🛍️ Vue Product Showcase - SPA E-Commerce

Aplicación Web de Página Única (SPA) desarrollada con **Vue 3**, **Vuex 4**, **Element Plus** y **Axios**. El proyecto consume la API de [FakeStoreAPI](https://fakestoreapi.com/) para presentar un catálogo interactivo de productos con filtrado por categorías, gestión de favoritos, conversión localizada de precios en pesos chilenos (CLP) y soporte para modo oscuro.

---

## 🛠️ Tecnologías y Arquitectura

- **Framework**: Vue 3 (Composition API con `<script setup>`)
- **Gestión de Estado**: Vuex 4 (Arquitectura modular: `products`, `filters`, `favorites`)
- **Librería UI**: Element Plus (`el-card`, `el-dialog`, `el-rate`, `el-switch`, etc.)
- **Cliente HTTP**: Axios
- **Testing Unitario**: Jest + Vue Test Utils v2
- **Testing E2E**: Cypress
- **Estilos**: CSS3 con Variables Dinámicas y Flexbox/Grid Responsive
